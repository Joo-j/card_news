# 축구 카드뉴스 (피치노트)

card_news 저장소의 축구 주제 스킬이다. 게시물은 피치노트(@pitchnote_) 계정에 올라간다. 기사 하나당 **이미지 한 장 + 상세 내용 텍스트 파일 하나**를 만든다. 이미지는 사진 위에 제목만 크게 얹은 썸네일이고, 구체적인 내용은 사용자가 인스타 업로드 때 본문에 붙여넣는 텍스트 파일에 담는다. 게시는 사용자가 직접 한다.

## 준비

스크립트는 Python 3.9+와 `feedparser`, `requests`, `Pillow`가 필요하다. 없으면 작업 폴더 밖(임시 폴더)에 가상환경을 만들어 설치한다. 스크립트 경로는 이 SKILL.md가 있는 폴더 기준 `scripts/`이다.

## 작업 순서

### 1. 기사 후보 수집

```bash
python3 scripts/fetch_news.py --hours 24
```

연합뉴스(국내), BBC Sport, The Guardian, Sky Sports, ESPN의 최근 기사가 `시각 | 출처 | 제목 | 요약 | 링크`로 나온다. 연합뉴스 피드는 스포츠 전체라 야구·골프 등이 섞여 있으니 축구만 본다.

출력 폴더(`posts/football/YYYY-MM-DD/`)와 그 전날 폴더에 이미 만든 게시물이 있으면 먼저 확인해 같은 사건을 다시 고르지 않는다.

### 2. 기사 선택

국내외를 가리지 않고 한국 팬이 가장 관심을 가질 기사를 고른다. 요청에 개수가 없으면 3~4건을 고른다.

- 우선: 한국 선수·대표팀 소식, 큰 경기 결과, 이적 확정, 감독 교체, 기록 경신, 스타 선수의 큰 사건
- 제외: 라이브 중계 페이지(`live-blog`, `/live/`), 영상·오디오 페이지, 퀴즈, 칼럼·의견 글, 하위 리그 단신, 근거가 약한 이적 루머 모음
- 같은 사건을 여러 매체가 다루면 하나로 묶고, 상세 내용에 출처를 함께 적는다

### 3. 본문 읽기

```bash
python3 scripts/read_article.py <기사 URL>
```

카드에 쓰는 사실은 모두 본문에서 확인한다. 요약만 보고 쓰면 숫자·날짜가 틀리기 쉽다. 같은 사건의 후속 기사가 있으면 함께 읽고 더 최신 사실을 쓴다.

기사 문장을 그대로 옮기지 않고 사실만 골라 직접 다시 쓴다. 기사 저작권은 언론사에 있고, 연합뉴스처럼 무단 전재와 AI 활용을 금지한다고 밝힌 곳도 있기 때문이다.

### 4. 배경 사진

기사에 실린 보도 사진(게티이미지, 연합뉴스 등)은 쓰지 않는다. 저작권 신고로 게시물이 내려가거나 계정이 제재될 수 있다. 위키미디어 공용에서 출처 표기만으로 쓸 수 있는 사진(CC BY, CC BY-SA, CC0, 퍼블릭 도메인)만 쓴다.

```bash
python3 scripts/find_photo.py search "Cristiano Ronaldo 2026"
python3 scripts/find_photo.py download "<파일 제목>" --out <임시 폴더>
```

`search`는 쓸 수 있는 라이선스만 보여 준다. 영문 이름과 한글 이름(예: `엄지성`)으로 모두 찾아본다. 최근 날짜, 세로 사진, 얼굴이 정면으로 크게 나온 사진이 좋다. 후보 몇 장을 내려받아 직접 열어 보고 고른다.

`download`는 사진과 같은 이름의 `.json`에 작가·라이선스·원본 주소를 저장한다. 이 정보는 상세 내용의 사진 출처 줄에 그대로 쓴다.

기사 주인공 사진이 없으면 같은 사건의 다른 핵심 인물 사진을 쓴다. 그것도 없으면 사용자에게 알리고 어떤 사진을 쓸지 묻는다.

### 5. 이미지 만들기

```bash
python3 scripts/render_card.py --photo <사진> --tag "<카테고리>" \
  --headline "<첫 줄>\n<둘째 줄>" --out posts/football/YYYY-MM-DD/<번호>_<짧은이름>.jpg \
  [--focus-y 0.15] [--focus-x 0.5] [--zoom 1.0]
```

- **tag**: 왼쪽 위 카테고리. 리그·대회 이름을 짧게 쓴다 (네이션스리그, 프리미어리그, K리그1, A매치, 아시안게임, 이적시장, 포르투갈 대표팀 등)
- **headline**: 두 줄. 첫 줄은 누가/무엇이, 둘째 줄은 결과. 한 줄은 공백 포함 11자 안팎이 가장 크게 보인다. 핵심 단어 하나를 `[ ]`로 감싸면 파란색으로 강조된다
- **focus-y / focus-x**: 사진에서 남길 위치 (0=위·왼쪽, 1=아래·오른쪽). 얼굴이 위쪽 3분의 2 안에 들어오게 맞춘다
- **zoom**: 선수가 작게 찍힌 전신 사진이면 1.5~1.8로 확대해 상반신이 크게 보이게 한다

제목 예시:

```
잉글랜드, 크로아티아에\n[7-0] 대승
17세 설리번,\n미국 [최연소 골] 경신
호날두, 선발 제외에\n대표팀 [전격 이탈]
한국, 한일전 꺾고\n아시안게임 [4연패]
```

만든 이미지는 반드시 직접 열어 본다. 얼굴이 잘리거나 제목과 겹치는지, 제목 아래 사진이 밝아 글자가 묻히지 않는지 확인하고, 문제가 있으면 focus·zoom을 바꾸거나 다른 사진으로 다시 만든다.

### 6. 상세 내용 텍스트

이미지와 같은 이름의 `.txt`로 저장한다. 사용자가 인스타 본문에 통째로 붙여넣는 글이다.

```
<제목 한 줄 (이미지 제목을 풀어 쓴 문장)>

<사실 문단 4~6개. 한 문단 1~2문장. 무엇이 일어났나 → 핵심 장면·기록 → 배경 → 반응 → 다음 일정>

<댓글을 부르는 질문 한 줄>

기사 출처
<매체명> <URL>

사진: <작가> / <라이선스> (위키미디어 공용)
<사진 원본 주소>

#해시태그 8~10개
```

- 선수·구단 이름은 국내 언론 표기를 따른다 (손흥민, 맨체스터 유나이티드). 국내 표기가 정해지지 않은 이름은 사용자에게 보고할 때 따로 알린다
- 기사에 없는 추측·평가·수치는 쓰지 않는다
- 사진 출처 줄은 라이선스 조건이므로 빠뜨리지 않는다
- 해시태그는 `#축구 #해외축구 #해축 #한국축구` 중 맞는 것 + 선수·팀·대회 이름

## 출력

```
posts/football/YYYY-MM-DD/
├── 1_<짧은이름>.jpg
├── 1_<짧은이름>.txt
├── 2_<짧은이름>.jpg
└── 2_<짧은이름>.txt
```

번호는 추천 업로드 순서(가장 화제성 높은 것이 1번)다. 내려받은 원본 사진은 임시 폴더에 두고 `posts/`에 넣지 않는다.

## 보고

사용자에게는 이렇게 알린다.

- 만든 게시물 표: 번호, 이미지 제목, 배경 사진 인물
- 파일 위치
- 확인이 필요한 것: 사진이 기사 시점과 다른 경우(예: 이전 소속팀 유니폼), 한글 표기를 직접 정한 이름, 사실관계가 매체마다 다른 부분
- 추천 업로드 순서
