# 축구 카드뉴스 (피치노트)

card_news 저장소의 축구 주제 스킬이다. 게시물은 피치노트(@pitchnote_) 계정에 올라간다. 기사 하나당 **이미지 한 장 + 상세 내용 텍스트 파일 하나**를 만든다. 이미지는 사진 위에 제목만 크게 얹은 썸네일이고, 구체적인 내용은 사용자가 인스타 업로드 때 본문에 붙여넣는 텍스트 파일에 담는다. 게시는 사용자가 직접 한다.

## 준비

스크립트는 Python 3.9+와 `feedparser`, `requests`, `Pillow`가 필요하다. 없으면 작업 폴더 밖(임시 폴더)에 가상환경을 만들어 설치한다. 스크립트 경로는 이 SKILL.md가 있는 폴더 기준 `scripts/`이다.

## 작업 순서

### 1. 기사 후보 수집

```bash
python3 scripts/fetch_news.py --hours 24
```

연합뉴스(국내), BBC Sport, The Guardian, Sky Sports(축구 전체·프리미어리그), ESPN의 최근 기사가 `시각 | 출처 | 제목 | 요약 | 링크`로 나온다. 연합뉴스 피드는 스포츠 전체라 야구·골프 등이 섞여 있으니 축구만 본다.

24시간 목록만 보면 며칠째 이어지는 큰 사건을 놓친다. `--hours 96`으로 한 번 더 뽑아, 여러 매체 제목에 반복해서 나오는 사건(판결, 징계, 감독 경질, 대형 이적 등)이 있는지 본다. 라이브 중계 페이지와 칼럼은 출처로 쓰지 않지만, 같은 사건이 그런 페이지에 계속 올라온다는 것은 지금 가장 뜨거운 이슈라는 신호다. 그런 사건은 가장 최근 진행 상황(항소, 징계 발표 등)을 다룬 일반 기사를 출처로 삼아 우선 후보에 넣는다.

출력 폴더(`posts/football/YYYY-MM-DD/`)와 그 전날 폴더에 이미 만든 게시물이 있으면 먼저 확인해 같은 사건을 다시 고르지 않는다.

### 2. 기사 선택

국내외를 가리지 않고 한국 팬이 가장 관심을 가질 기사를 고른다. 요청에 개수가 없으면 3~4건을 고른다.

- 우선: 며칠째 이어지는 큰 사건의 최신 진행 상황, 한국 선수·대표팀 소식, 큰 경기 결과, 이적 확정, 감독 교체, 기록 경신, 스타 선수의 큰 사건
- 제외: 라이브 중계 페이지(`live-blog`, `/live/`), 영상·오디오 페이지, 퀴즈, 칼럼·의견 글, 하위 리그 단신, 근거가 약한 이적 루머 모음
- 같은 사건을 여러 매체가 다루면 하나로 묶고, 상세 내용에 출처를 함께 적는다
- 후보 목록에서 기사를 찾을 때는 한글 키워드만 쓰지 않는다. 해외 매체 기사는 영문으로만 나오므로 선수 영문 이름, 구단명, `transfer`, `injury`, `sacked` 같은 영문 단어로도 찾는다

**후보를 보여 주기 전에 주인공 사진부터 찾는다.** 기사 주인공(발언한 사람, 사건의 당사자)의 얼굴이 나온 사진을 4단계 방법으로 찾을 수 없으면 그 기사는 후보에 올리지 않는다. 다른 선수 사진으로 대신하는 안도 만들지 않는다. 사진이 있는 기사만 후보로 보여 주고, 각 후보에 어떤 사진이 있는지(인물, 연도, 소속팀)를 함께 적는다.

### 3. 본문 읽기

```bash
python3 scripts/read_article.py <기사 URL>
```

카드에 쓰는 사실은 모두 본문에서 확인한다. 요약만 보고 쓰면 숫자·날짜가 틀리기 쉽다. 같은 사건의 후속 기사가 있으면 함께 읽고 더 최신 사실을 쓴다.

기사 문장을 그대로 옮기지 않고 사실만 골라 직접 다시 쓴다. 기사 저작권은 언론사에 있고, 연합뉴스처럼 무단 전재와 AI 활용을 금지한다고 밝힌 곳도 있기 때문이다.

### 4. 배경 사진

기사에 실린 보도 사진(게티이미지, 연합뉴스 등)은 쓰지 않는다. 저작권 신고로 게시물이 내려가거나 계정이 제재될 수 있다. 위키미디어 공용에서 출처 표기만으로 쓸 수 있는 사진(CC BY, CC BY-SA, CC0, 퍼블릭 도메인)만 쓴다.

```bash
python3 scripts/find_photo.py search "Cristiano Ronaldo 2026"
python3 scripts/find_photo.py download "<파일 제목>" --out <임시 폴더>
```

`search`는 쓸 수 있는 라이선스만 보여 준다. 영문 이름과 한글 이름(예: `엄지성`)으로 모두 찾아본다. 최근 날짜, 세로 사진, 얼굴이 정면으로 크게 나온 사진이 좋다. 후보 몇 장을 내려받아 직접 열어 보고 고른다.

선수 이름에 대회·경기명을 붙여 찾으면(예: `Harry Kane England v Panama`) 경기 현장이나 실제 플레이 장면이 먼저 나온다. 구단 로고, 선수가 없는 경기장·라커룸 사진, 스톡 이미지, 글자가 덮인 배너·포스터는 쓰지 않는다.

`download`는 사진과 같은 이름의 `.json`에 작가·라이선스·원본 주소를 저장한다. 이 정보는 상세 내용의 사진 출처 줄에 그대로 쓴다.

사진은 기사 주인공의 얼굴이 잘 보이는 것을 우선 찾는다. 이적한 선수의 옛 팀 유니폼처럼 기사 내용과 어긋날 수 있는 점이 있으면 표시해 둔다.

**사진이 적당한지는 사용자가 판단한다.** 후보 사진을 이미지로 만들어 보여 주고, 각 사진의 장단점(옛 유니폼, 해상도, 촬영 연도 등)과 어디까지 찾아봤는지를 함께 알린다. 쓸 만한 사진을 찾지 못했어도 기사를 빼거나 파일을 지우지 말고, 상황을 알린 뒤 사용자의 결정을 기다린다.

### 5. 이미지 만들기

```bash
python3 scripts/render_card.py --photo <사진> --tag "<카테고리>" \
  --headline "<첫 줄>\n<둘째 줄>" --out posts/football/YYYY-MM-DD/<번호>_<짧은이름>.jpg \
  [--focus-y 0.15] [--focus-x 0.5] [--zoom 1.0]
```

- **tag**: 왼쪽 위 카테고리. 리그·대회 이름을 짧게 쓴다 (네이션스리그, 프리미어리그, K리그1, A매치, 아시안게임, 이적시장, 포르투갈 대표팀 등)
- **headline**: 두 줄. 첫 줄은 누가/무엇이, 둘째 줄은 결과. 한 줄은 공백 포함 11자 안팎이 가장 크게 보인다. 핵심 단어 하나를 `[ ]`로 감싸면 파란색으로 강조된다
- **focus-y / focus-x**: 사진에서 남길 위치 (0=위·왼쪽, 1=아래·오른쪽). 얼굴이 위쪽 3분의 2 안에 들어오게 맞춘다
- **zoom**: 선수가 작게 찍힌 전신 사진이면 1.5~1.8로 확대해 상반신이 크게 보이게 한다

속보 모양(`--style breaking`)은 아래 세 조건을 모두 갖춘 소식에만 쓴다. 하나라도 빠지면 기본 모양을 쓴다.

- **새로 확정된 사실**: 구단·협회·리그·선수 본인의 공식 발표나 경기 중 실제로 일어난 일(판결, 경질, 은퇴 선언, 이적 확정, 부상 진단, 징계 등). "~할 듯", "~ 가능성", 루머, 반응·분석 기사는 해당하지 않는다
- **첫 보도 후 6시간 이내**: 지금 시각과 첫 보도 시각을 비교한다. 국내 매체가 이미 "[속보]", "[오피셜]"로 반나절 넘게 다룬 소식은 늦었다
- **이 계정에서 처음 다루는 사건**: 이미 다룬 사건의 후속이면 새 사실이 그 자체로 큰 소식일 때만 해당한다

오피셜 모양(`--style official`)은 속보와 같은 모양에 라벨만 `[오피셜]`이다. 아래 조건을 모두 갖춘 소식에 쓴다.

- **당사자의 공식 발표**: 구단·협회·리그 공식 채널의 발표, 선수·감독 본인이 낸 입장문이나 SNS 게시물(이적·재계약 발표, 수상, 징계 확정, 공식 사과 등). 기자 취재로 알려진 내용, "소식통에 따르면"은 해당하지 않는다
- **첫 보도 후 24시간 이내**
- **이 계정에서 처음 다루는 발표**

몇 시간 안에 터진 큰 사건이면서 공식 발표이기도 하면 `[속보]`를 쓴다. 어느 쪽에도 맞지 않으면 기본 모양을 쓴다.

속보·오피셜 후보를 찾을 때는 RSS 목록만으로는 부족하다. `scripts/search_news.py`로 최근 하루 안의 "오피셜", "공식", "경질", "은퇴", "부상", "sacked", "confirmed", "official" 같은 말이 들어간 제목을 찾고, 첫 보도 시각을 확인한다. 조건에 맞는 소식이 없으면 없다고 보고하고 기본 모양 후보를 제안한다.

```bash
python3 scripts/search_news.py 오피셜 경질 은퇴 부상 --hours 12
python3 scripts/search_news.py sacked confirmed official injury --lang en --hours 12
```

속보 모양은 카테고리 대신 흰색 `[속보]` 라벨이 제목 위에 붙고, 제목 전체가 연두색으로 크게 들어가며, 계정 아이디는 하단 가운데로 간다. `--tag`는 쓰지 않고, 라벨은 `--label 오피셜`처럼 바꿀 수 있다. 제목은 한두 줄, 한 줄 9자 안팎으로 짧게 쓰고 `[ ]` 강조는 쓰지 않는다. 속보가 아닌 소식에 이 모양을 쓰면 계정 신뢰가 떨어지므로 그 외에는 기본 모양을 쓴다.

```
--style breaking --headline "호날두\n대표팀 이탈"
--style official --headline "이강인\n이달의 선수"
```

두 사람을 맞세우는 기사(라이벌, 수상 경쟁, 감독 대결 등)는 `--photo2 <사진> [--focus2-y] [--focus2-x] [--zoom2]`를 더해 좌우 분할 이미지로 만든다. 왼쪽이 `--photo`, 오른쪽이 `--photo2`이고 가운데에 VS 표시가 들어간다. 두 사람이 함께 나온 사진이 있으면 그 사진 한 장이 더 낫다. 제목의 이름 순서는 사진의 왼쪽·오른쪽 순서와 맞추고, 어느 한쪽 편을 드는 것처럼 보이지 않게 `[vs]`를 강조한다. 상세 내용에는 두 사진의 출처를 모두 적는다.

제목 예시:

```
잉글랜드, 크로아티아에\n[7-0] 대승
17세 설리번,\n미국 [최연소 골] 경신
호날두, 선발 제외에\n대표팀 [전격 이탈]
한국, 한일전 꺾고\n아시안게임 [4연패]
발롱도르 주인공은?\n야말 [vs] 케인
```

제목과 카테고리에 한자(日, 韓, 英 등)를 쓰지 않는다. 글꼴에 한자가 없어 네모로 깨진다. "일본", "한국"처럼 한글로 쓴다.

만든 이미지는 반드시 직접 열어 본다. 얼굴이 잘리거나 제목과 겹치는지, 제목 아래 사진이 밝아 글자가 묻히지 않는지 확인하고, 문제가 있으면 focus·zoom을 바꾸거나 다른 사진으로 다시 만든다.

### 6. 상세 내용 텍스트

이미지와 같은 이름의 `.txt`로 저장한다. 사용자가 인스타 본문에 통째로 붙여넣는 글이다.

```
<제목 한 줄 (이미지 제목을 풀어 쓴 문장)>

<사실 문단 4~6개. 한 문단 1~2문장. 무엇이 일어났나 → 핵심 장면·기록 → 배경 → 반응 → 다음 일정>

<댓글을 부르는 질문 한 줄>

기사 출처
<매체명> <URL>

사진: <작가> / <라이선스> (위키미디어 공용)
<사진 원본 주소>

#해시태그 8~10개
```

- 선수·구단 이름은 국내 언론 표기를 따른다 (손흥민, 맨체스터 유나이티드). 국내 표기가 정해지지 않은 이름은 사용자에게 보고할 때 따로 알린다
- 기사에 없는 추측·평가·수치는 쓰지 않는다
- 사진 출처 줄은 라이선스 조건이므로 빠뜨리지 않는다
- 해시태그는 `#축구 #해외축구 #해축 #한국축구` 중 맞는 것 + 선수·팀·대회 이름

## 출력

```
posts/football/YYYY-MM-DD/
├── 1_<짧은이름>.jpg
├── 1_<짧은이름>.txt
├── 2_<짧은이름>.jpg
└── 2_<짧은이름>.txt
```

번호는 추천 업로드 순서(가장 화제성 높은 것이 1번)다. 내려받은 원본 사진은 임시 폴더에 두고 `posts/`에 넣지 않는다.

## 보고

사용자에게는 이렇게 알린다.

- 만든 게시물 표: 번호, 이미지 제목, 배경 사진 인물
- 파일 위치
- 확인이 필요한 것: 사진이 기사 시점과 다른 경우(예: 이전 소속팀 유니폼), 한글 표기를 직접 정한 이름, 사실관계가 매체마다 다른 부분
- 추천 업로드 순서
