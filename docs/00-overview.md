# 카드뉴스 프로젝트

## 목적

card_news는 주제별 인스타그램 계정에 올릴 카드뉴스 게시물을 만드는 저장소입니다.

주제마다 기사를 모으고 고르는 기준, 이미지 모양, 올릴 계정이 다릅니다. 그래서 주제 하나를 Claude 스킬 하나로 만들고, 공통 규칙과 폴더 구조만 이 문서에서 정합니다.

유료 API 없이 Claude와의 대화 안에서 기사 선택과 글쓰기를 처리하며, 게시는 사용자가 인스타그램에서 직접 합니다.

## 게시물

게시물 하나는 기사 하나에 대응하며 아래 두 가지 파일로 이루어집니다.

- **이미지**: 업로드할 때 올리는 사진입니다. 한 장일 수도, 옆으로 넘겨 보는 여러 장일 수도 있습니다. 크기, 모양, 장 수는 주제 문서에서 정합니다.
- **상세 내용**: 기사의 사실을 정리한 글, 출처, 사진 출처, 해시태그를 담은 텍스트 파일입니다. 업로드할 때 본문에 통째로 붙여넣습니다.

두 파일은 확장자만 다르고 이름이 같습니다. 이미지가 여러 장이면 이미지 이름 뒤에 `_01`, `_02`처럼 장 순서를 붙입니다. 이름 앞의 번호는 그날의 추천 업로드 순서입니다.

## 폴더 구조

저장소는 스킬, 문서, 게시물 세 갈래로 나뉩니다.

```
card_news/
├── skills/
│   ├── <주제>-card-news/       주제별 스킬 폴더
│   └── <주제>-card-news.skill  Claude 앱 설치 파일
├── docs/
│   ├── 00-overview.md          이 문서
│   ├── 01-<주제>.md            주제별 스펙
│   └── build_html.py           읽기용 HTML 생성
└── posts/
    └── <주제>/YYYY-MM-DD/      만든 게시물 (git에 올리지 않음)
```

## 주제별 스킬 구성

모든 주제 스킬은 같은 구성을 따르며, 폴더 하나만 있으면 다른 컴퓨터에서도 같은 결과를 냅니다.

| 파일 | 역할 |
|---|---|
| `SKILL.md` | Claude가 따르는 작업 순서와 규칙 |
| `scripts/fetch_news.py` | RSS에서 기사 후보 목록 출력. 피드 목록은 파일 위쪽 `FEEDS` |
| `scripts/search_news.py` | 뉴스 검색에서 키워드별 최신 기사와 첫 보도 시각 출력. 속보·오피셜 후보 찾기용 |
| `scripts/read_article.py` | 기사 본문 문단 추출 |
| `scripts/find_photo.py` | 위키미디어 사진 검색과 내려받기, 작가·라이선스 기록 |
| `scripts/render_card.py` | 이미지(표지) 생성. 계정 아이디 기본값은 `--handle` |
| `scripts/render_slide.py` | 캐러셀 내용 장 생성. 정보 장과 인용 장 두 모양 |
| `assets/fonts/` | 글꼴과 라이선스 |

스크립트는 Python 3.9 이상과 `feedparser`, `requests`, `Pillow`를 사용합니다.

스킬마다 스크립트와 글꼴을 따로 가집니다. **한 주제의 스크립트를 고쳐도 다른 주제에는 반영되지 않으므로**, 모든 주제에 필요한 수정이면 각 스킬에 같이 적용합니다.

## 새 주제 추가

새 주제는 기존 스킬 폴더를 복사해 주제에 맞게 바꾸는 것으로 시작합니다.

1. `skills/football-card-news/`를 `skills/<주제>-card-news/`로 복사합니다.
2. `SKILL.md`의 `name`, `description`, 기사 선택 기준, 카테고리 예시, 해시태그, 출력 경로(`posts/<주제>/`)를 바꿉니다.
3. `scripts/fetch_news.py`의 `FEEDS`를 그 주제의 RSS로 바꿉니다.
4. `scripts/render_card.py`와 `scripts/render_slide.py`의 `--handle` 기본값을 그 주제의 계정 아이디로 바꿉니다. 필요하면 색과 배치도 바꿉니다.
5. `docs/01-<주제>.md` 스펙을 쓰고 `docs/build_html.py`의 `DOCUMENTS`와 이 문서의 주제 목록에 추가합니다.
6. `.skill` 설치 파일을 만듭니다.

Claude에게 "<주제> 카드뉴스 스킬 새로 만들어줘"라고 요청하면 위 순서대로 처리합니다.

`description`에는 그 주제의 요청에만 스킬이 쓰이도록 범위를 분명히 적습니다. 범위가 겹치면 다른 주제의 요청에 엉뚱한 스킬이 쓰입니다.

## 스킬 설치

스킬은 Claude Code와 Claude 앱 중 쓰는 환경에 맞춰 설치합니다.

- **Claude 앱**: `skills/<주제>-card-news.skill` 파일을 스킬로 추가합니다.
- **Claude Code, 모든 프로젝트**: `skills/<주제>-card-news` 폴더를 `~/.claude/skills/` 아래에 복사합니다.
- **Claude Code, 이 저장소만**: 같은 폴더를 저장소의 `.claude/skills/` 아래에 복사합니다.

`SKILL.md`나 스크립트를 고치면 `.skill` 파일을 다시 만들어야 앱에 반영됩니다. Claude에게 "<주제> 카드뉴스 스킬 다시 패키징해줘"라고 요청하면 됩니다.

## 게시물 보관

게시물은 `posts/<주제>/YYYY-MM-DD/`에 저장하며, `posts/`는 git에 올리지 않습니다(`.gitignore`).

이미 다룬 사건을 거르는 판단은 작업하는 컴퓨터에 남아 있는 `posts/<주제>/` 폴더만 기준으로 합니다. 내려받은 원본 사진은 임시 폴더에 두고 `posts/`에 넣지 않습니다.
