# 피치노트 축구 카드뉴스

## 목적

피치노트(@pitchnote_) 인스타그램 계정에 올릴 축구 소식 게시물을 만드는 작업 방식입니다.

국내외 축구 기사에서 화제성 있는 소식을 골라, 한눈에 주제가 보이는 이미지 한 장과 본문에 붙일 상세 내용을 만듭니다. 게시는 사용자가 인스타그램에서 직접 합니다.

유료 API 없이 Claude와의 대화 안에서 기사 선택과 글쓰기를 처리합니다. 반복되는 수집, 사진 검색, 이미지 생성은 스킬에 들어 있는 스크립트가 맡습니다.

## 주요 개념

게시물 하나는 기사 하나에 대응하며 아래 두 파일로 이루어집니다.

- **이미지**: 선수 사진을 배경으로 카테고리, 계정 아이디, 두 줄 제목을 얹은 1080×1350 JPEG입니다. 업로드할 때 이 한 장만 올립니다.
- **상세 내용**: 기사의 사실을 정리한 글, 출처, 사진 출처, 해시태그를 담은 텍스트 파일입니다. 업로드할 때 본문에 통째로 붙여넣습니다.

배경 사진은 위키미디어 공용에서 출처 표기만으로 쓸 수 있는 사진만 씁니다. 기준은 [배경 사진 기준](#배경-사진-기준)에 있습니다.

## 기사 수집

기사 후보는 다섯 곳의 RSS 피드에서 최근 24시간 분량을 모읍니다.

| 출처 | 범위 | 피드 주소 |
|---|---|---|
| 연합뉴스 | 국내 스포츠 전체 | `https://www.yna.co.kr/rss/sports.xml` |
| BBC Sport | 축구 | `https://feeds.bbci.co.uk/sport/football/rss.xml` |
| The Guardian | 축구 | `https://www.theguardian.com/football/rss` |
| Sky Sports | 축구 | `https://www.skysports.com/rss/11095` |
| ESPN | 축구 | `https://www.espn.com/espn/rss/soccer/news` |

연합뉴스 피드에는 야구, 농구, 골프 기사가 함께 들어 있어 축구 기사만 골라 씁니다. 피드 목록은 `scripts/fetch_news.py`의 `FEEDS`에 있습니다.

## 기사 선택 기준

국내외를 구분하지 않고 한국 팬의 관심이 가장 클 기사를 고르며, 하루 3~4건이 기본입니다.

우선하는 소식은 한국 선수와 대표팀 소식, 큰 경기 결과, 이적 확정, 감독 교체, 기록 경신, 스타 선수의 큰 사건입니다.

라이브 중계 페이지, 영상·오디오 페이지, 퀴즈, 칼럼, 하위 리그 단신, 근거가 약한 이적 루머 모음은 제외합니다. 같은 사건을 여러 매체가 다루면 하나로 묶고 출처를 함께 적습니다.

이미 만든 게시물과 같은 사건은 다시 고르지 않습니다. 그날과 전날의 `posts/` 폴더가 판단 기준입니다.

## 이미지 규격

이미지는 인스타그램 세로 비율(4:5)에 맞춘 1080×1350 JPEG입니다.

| 요소 | 위치 | 글꼴 | 색 |
|---|---|---|---|
| 배경 사진 | 화면 전체, 비율을 유지해 잘라 맞춤 | 없음 | 아래쪽 64%부터 검은 그라데이션 |
| 카테고리 | 왼쪽 위 | Pretendard Bold 34px, 앞에 점 | 흰색, 점은 파란색 |
| 계정 아이디 | 제목 바로 위 | Pretendard Bold 32px | 연회색 |
| 제목 | 왼쪽 아래, 두 줄 | Pretendard Black 72~104px | 흰색, 강조 단어는 파란색 |

파란색은 `#3D7BFF`입니다. 제목은 가장 긴 줄이 좌우 여백 64px 안에 들어오도록 크기가 자동으로 줄어들며, 72px보다 작아지지는 않습니다.

**제목은 두 줄이며 한 줄은 공백 포함 11자 안팎으로 씁니다.** 첫 줄에는 누가 또는 무엇이, 둘째 줄에는 결과를 놓고, 핵심 단어 하나를 강조합니다.

```
잉글랜드, 크로아티아에
[7-0] 대승
```

카테고리는 리그나 대회 이름을 짧게 씁니다. 네이션스리그, 프리미어리그, K리그1, A매치, 아시안게임, 이적시장, 포르투갈 대표팀 같은 형태입니다.

## 상세 내용 형식

상세 내용은 이미지와 같은 이름의 텍스트 파일이며, 아래 순서로 씁니다.

```
<제목 문장>

<사실 문단 4~6개>

<댓글을 부르는 질문 한 줄>

기사 출처
<매체명> <URL>

사진: <작가> / <라이선스> (위키미디어 공용)
<사진 원본 주소>

#해시태그 8~10개
```

사실 문단은 무엇이 일어났는지, 핵심 장면과 기록, 배경, 반응, 다음 일정의 순서로 씁니다. 한 문단은 한두 문장입니다.

기사에 없는 추측, 평가, 수치는 쓰지 않습니다. 기사 문장을 옮기지 않고 사실만 골라 새로 씁니다. 연합뉴스처럼 무단 전재와 AI 활용을 금지한다고 밝힌 매체가 있기 때문입니다.

선수와 구단 이름은 국내 언론의 표기를 따릅니다. 국내 표기가 정해지지 않은 이름을 쓴 경우에는 사용자에게 따로 알립니다.

## 배경 사진 기준

배경 사진은 위키미디어 공용에서 아래 라이선스로 공개된 사진만 씁니다.

| 라이선스 | 출처 표기 | 같은 조건 공유 |
|---|---|---|
| CC BY | 필요 | 불필요 |
| CC BY-SA | 필요 | 필요 |
| CC0, 퍼블릭 도메인 | 불필요 | 불필요 |

**기사에 실린 보도 사진은 쓰지 않습니다.** 게티이미지, 연합뉴스 같은 통신사 사진은 저작권 신고로 게시물이 삭제되거나 계정이 제재될 수 있습니다.

출처 표기가 필요 없는 사진이라도 상세 내용에는 사진 출처 줄을 항상 남깁니다. CC BY-SA 사진으로 만든 이미지는 같은 라이선스를 따르며, 사진 출처 줄의 라이선스 표기가 그 고지를 겸합니다.

사진은 최근 날짜, 세로 구도, 얼굴이 정면으로 크게 나온 것을 고릅니다. 기사 주인공 사진이 없으면 같은 사건의 다른 핵심 인물 사진을 쓰고, 그것도 없으면 사용자에게 묻습니다.

## 파일 배치

게시물은 작업 날짜별 폴더에 번호와 짧은 이름으로 저장합니다.

```
posts/2026-10-04/
├── 1_잉글랜드_크로아티아.jpg
├── 1_잉글랜드_크로아티아.txt
├── 2_설리번_최연소골.jpg
└── 2_설리번_최연소골.txt
```

번호는 추천 업로드 순서이며, 화제성이 가장 높은 게시물이 1번입니다. 내려받은 원본 사진은 임시 폴더에 두고 `posts/`에 넣지 않습니다.

`posts/`는 git에 올리지 않습니다(`.gitignore`). 이미 다룬 사건을 거르는 판단은 작업하는 컴퓨터에 남아 있는 `posts/` 폴더만 기준으로 합니다.

## 스킬 구성

이 작업 방식은 `skills/pitchnote-card-news/` 스킬로 묶여 있으며, 저장소만 받으면 다른 컴퓨터에서도 같은 결과를 냅니다.

| 파일 | 역할 |
|---|---|
| `SKILL.md` | Claude가 따르는 작업 순서와 규칙 |
| `scripts/fetch_news.py` | RSS에서 기사 후보 목록 출력 |
| `scripts/read_article.py` | 기사 본문 문단 추출 |
| `scripts/find_photo.py` | 위키미디어 사진 검색과 내려받기, 작가·라이선스 기록 |
| `scripts/render_card.py` | 이미지 생성 |
| `assets/fonts/` | Pretendard Black·Bold 글꼴과 라이선스(SIL OFL) |

스크립트는 Python 3.9 이상과 `feedparser`, `requests`, `Pillow`를 사용합니다.

## 스킬 설치

스킬은 Claude Code와 Claude 앱 중 쓰는 환경에 맞춰 설치합니다.

- **Claude 앱**: `skills/pitchnote-card-news.skill` 파일을 스킬로 추가합니다.
- **Claude Code, 모든 프로젝트**: `skills/pitchnote-card-news` 폴더를 `~/.claude/skills/` 아래에 복사합니다.
- **Claude Code, 이 저장소만**: 같은 폴더를 저장소의 `.claude/skills/` 아래에 복사합니다.

설치 뒤에는 "오늘 축구 카드뉴스 만들어줘", "이 기사로 피치노트 게시물 하나 만들어줘"처럼 요청하면 스킬이 사용됩니다.

`SKILL.md`나 스크립트를 고치면 `.skill` 파일을 다시 만들어야 앱에 반영됩니다. Claude에게 "카드뉴스 스킬 다시 패키징해줘"라고 요청하면 됩니다.
